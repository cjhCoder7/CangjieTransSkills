# 样本目录

用于存放小体量、易验证的样本工程或片段。

当前使用原则：

- 优先选择功能单一、依赖少、能快速运行的 ArkTS 示例；
- 不要一开始把完整 Telegram 工程直接放入本目录；
- 每个样本都应有来源、用途、验证方式和当前状态说明。

当前样本：

- `ui-routing-defining-page-layout/`
  - UI / 路由样本，覆盖列表 / 网格布局、分类过滤、详情跳转与返回。
- `data-persistence-001/`
  - Preferences 持久化样本，覆盖通用存储接口、Harmony Preferences 实现、Fake Store 与业务层单测骨架。
