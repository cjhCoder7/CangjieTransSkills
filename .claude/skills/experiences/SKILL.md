# 经验记录

所有仓颉相关 skill（翻译、构建、UI 验证等）共用同一个文件：`experiences.md`。**不按领域或主题拆分**，遇到非显而易见问题并已验证解决方案后，直接在文件末尾追加一条即可。

记录是**建议性动作**，不是 LoopX 结案的必需条件；只在确实值得复用时才写，避免为了记录而记录。

## 单条记录格式

```markdown
### YYYY-MM-DD 简短标题

- 现象：...
- 原因：...
- 方案：...
```

## 使用方式

- **查阅**：开始翻译/构建/UI 验证前，可以扫一眼 `experiences.md` 有没有类似问题的记录
- **记录**：解决了非显而易见问题（不是随手就能查到的坑）后，在文件末尾追加一条，标题简短即可
- 只记**已验证**的问题和方案，未验证的猜测不要写进来
