# 术语表

- `Cangjie / 仓颉`
  - 华为相关生态中的编程语言，本项目的目标语言。

- `HarmonyOS / 鸿蒙`
  - 本项目重点面向的系统与应用生态。

- `ArkTS`
  - HarmonyOS 应用开发的重要源语言之一，也是本项目当前第一优先级翻译来源。

- `Swift`
  - Telegram iOS 版本对应的重要源语言之一，计划在 ArkTS 验证稳定后推进。

- `Skill`
  - 面向 Agent 的结构化能力单元，可包含知识、规则、脚本、示例与检索方式。

- `Agent`
  - 负责规划、检索、生成、验证、迭代的智能体执行层。

- `Pipeline`
  - 从文档整理、Skill 生成、翻译、验证到结果沉淀的一整套流程。

- `小样本验证`
  - 在正式处理大型工程前，先用体量小、依赖少、功能明确的样本验证技术路线。

- `轨迹信息`
  - 指翻译与验证过程中的关键输入、步骤、结果、日志与问题记录，用于复现与验收。

- `DevEco Studio`
  - HarmonyOS 官方开发环境，本项目开发与验证的关键工具。
