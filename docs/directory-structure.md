# 目录结构说明

## 根目录

- `README.md`
  - 项目入口说明与阅读顺序。
- `AGENTS.md`
  - 人类与 AI Agent 协作总纲。
- `idea.md`
  - 原始会议纪要，仅用于追溯最初讨论背景。

## 文档目录

- `docs/`
  - 项目正式文档。
- `docs/decisions/`
  - 决策记录，例如目录方案、Skill 模板、工具选型、评测口径。
- `docs/reports/`
  - 周报、实验复盘、阶段总结。
- `docs/samples/`
  - 单个样本的完整翻译记录。
- `docs/traces/`
  - 单次执行链路的完整轨迹。

## 研发支撑目录

- `research/`
  - 用于存放样本分析、文档摘录、映射表、实验设计草稿。
- `scripts/`
  - 用于存放文档清洗、检索、转换、评测等脚本。
- `skills/`
  - 用于存放项目自建 Skill 内容或模板。
- `samples/`
  - 用于存放最小验证样本，不建议一开始放大型外部工程。
- `third_party/`
  - 用于存放外部参考仓库镜像或裁剪版代码，必须附带来源说明。
- `artifacts/`
  - 用于存放生成产物、日志、翻译轨迹、评测结果。

## 放置约定

- 正式说明放 `docs/`；
- 中间研究材料放 `research/`；
- 可执行工具放 `scripts/`；
- 外部代码不直接混入业务目录，优先放 `third_party/`；
- 大型生成物不要直接散落在根目录；
- 敏感配置不纳入版本控制。
