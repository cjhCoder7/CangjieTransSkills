# 小样本记录模板

## 1. 文档目的

本模板用于记录第一批及后续所有小样本的翻译验证过程，尤其适用于以下四类样本：

1. UI / 路由
2. 持久化
3. 网络
4. 日志 / DFX

本模板的目标不是只保存“最后代码”，而是完整记录：

- 为什么选这个样本；
- 它验证哪类 Skill；
- ArkTS 到仓颉的转换过程；
- 遇到了哪些难点；
- 如何设计单元测试；
- 最终哪些结论应回写到 Skill 与评测体系。

## 2. 使用规则

- 每个样本建议单独建立一份记录文件；
- 文件名建议使用：

```text
sample-<domain>-<sample-name>-record.md
```

**示例**：

```text
sample-ui-defining-page-layout-record.md
sample-storage-preferences-record.md
sample-network-http-record.md
sample-dfx-logger-record.md
```

- 记录时不要省略失败过程；
- 若一个样本经历多轮较大修改，可在同一文档中分轮次记录，或拆成多份并互相引用；
- 关键结论应同步回写到 Skill 或执行轨迹文件。
